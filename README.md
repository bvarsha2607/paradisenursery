# 🌿 Paradise Nursery – Online Plant Shop

## 📌 Project Overview

**Paradise Nursery** is a dynamic e-commerce web application for an online plant shop. The application allows users to browse different plants, view plant details, add plants to a shopping cart, and manage their cart items easily.

The project focuses on creating a **user-friendly shopping experience** with interactive features such as dynamic cart updates, quantity management, and automatic total cost calculation.

---

## 🎯 Project Objective

The main objective of this project is to build a functional online plant shopping application by applying web development concepts learned through previous practice projects.

Users can:

* Browse available plants
* View plant information
* Add plants to the shopping cart
* Increase or decrease item quantities
* Remove items from the cart
* View the updated cart count
* Automatically calculate the total cost

---

## ✨ Features

### 🏠 Home Page

* Displays the Paradise Nursery brand and introduction.
* Provides easy navigation to the plant shopping section.

### 🌱 Plant Collection

* Displays different plants available for purchase.
* Shows plant **image, name, description, and price**.
* Provides an **Add to Cart** option for each plant.

### 🛒 Shopping Cart

* Displays all selected plants.
* Shows the quantity of each plant.
* Allows users to increase or decrease quantities.
* Allows users to remove plants from the cart.
* Dynamically updates the cart item count.

### 💰 Dynamic Price Calculation

* Calculates the price based on the selected quantity.
* Automatically updates the total cost when items are added, removed, or modified.

### 🧭 Navigation Bar

* Provides easy navigation between different sections/pages.
* Includes access to the shopping cart.

## 🔄 How the Application Works

1. The user opens the **Paradise Nursery** website.
2. The user browses the available plants.
3. Each plant displays its image, name, description, and price.
4. The user clicks **Add to Cart** to select a plant.
5. The selected plant appears in the shopping cart.
6. The user can increase or decrease the quantity.
7. The user can remove unwanted items.
8. The cart quantity and total price are updated dynamically.

---

## 🛒 Shopping Cart Functionality

The shopping cart provides the following operations:

| Function          | Description                            |
| ----------------- | -------------------------------------- |
| Add to Cart       | Adds a selected plant to the cart      |
| Increase Quantity | Increases the quantity of a plant      |
| Decrease Quantity | Decreases the quantity of a plant      |
| Remove Item       | Removes a plant from the cart          |
| Cart Count        | Displays the number of selected items  |
| Total Cost        | Calculates the total price dynamically |

## 🚀 Getting Started

### Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Navigate to the project directory:

```bash
cd Paradise-Nursery
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will then be available in your browser.
