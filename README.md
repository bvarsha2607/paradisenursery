# Paradise Nursery

## Project Name
Paradise Nursery – Online Plant Shopping Cart Application

## Project Description
Paradise Nursery is an online plant shopping web application. It allows users to browse plants, view plant details, add plants to a shopping cart, and manage cart items.

## Features
- Browse different plants
- View plant images, names, descriptions, and prices
- Add plants to the cart
- Increase or decrease item quantity
- Remove items from the cart
- Automatically calculate the total cost
- Easy navigation using a navigation bar

## Technologies Used
- HTML
- CSS
- JavaScript
- React

## Purpose
The main purpose of this project is to build a simple and user-friendly e-commerce website and apply the web development skills learned through previous practice projects.
